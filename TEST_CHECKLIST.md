# Чеклист ручной проверки в Godot 4.6

Проект: **Paranoia Protocol: Bunker** · Ветка: `claude/magical-ardinghelli` · Main scene: `scenes/levels/bunker_entrance.tscn`

## 1. Запуск

- [ ] Открыть `project.godot` в Godot 4.6.2 (Forward+)
- [ ] При первом запуске редактор импортирует все `.jpg`/`.glb`/`.png` — дождаться завершения, лог без критических ошибок
- [ ] В `Project → Project Settings → Autoload`: **нет** Talo / TaloGlobal в списке; есть EventBus, GameManager, ParanoiaManager, InventoryManager, SaveManager
- [ ] В `Project → Project Settings → Plugins`: `talo` отсутствует
- [ ] F5 → стартует `bunker_entrance` (НЕ opening-меню)
- [ ] В логе **нет** строк `Talo`, `Bearer <token>`, `socket_ticket`

## 2. Графика — bunker_entrance

- [ ] Пол — бетон с видимой текстурой (НЕ сплошной серый цвет, НЕ зелёная трава)
- [ ] Стены — бетонная текстура с normal-картой (видна шероховатость при движении)
- [ ] Потолок — бетонная текстура
- [ ] Стол — ржавая металлическая текстура, стоит у западной стены
- [ ] На столе лежит светло-бежевый прямоугольник (записка)
- [ ] Лампа в центре потолка мерцает: 2с свет → 0.5с дёрганье → 1с темнота → цикл
- [ ] Общая атмосфера тёмная, filmic тон, слабый bloom, туман (fog) виден у дальних стен
- [ ] Перед игроком — входная дверь (interactable_door) около z=1.9
- [ ] За игроком (на севере) — выходная дверь, ведёт в коридор
- [ ] Справа у восточной стены — ящик (amnesia-style drawer)

## 3. Графика — bunker_corridor

- [ ] Длинный коридор 10м × 2.5м
- [ ] Одна рабочая OmniLight в начале (жёлтый тёплый свет)
- [ ] Глубже по коридору — 2 "мёртвых" лампы с почти нулевой energy (0.05)
- [ ] На северной стене — красная надпись «ОНИ СЛЫШАТ» (Label3D)
- [ ] Сильный fog (density 0.15) — дальний конец теряется в тумане
- [ ] На полу у левой стены — маленькая батарейка (ржавый металл)

## 4. Механики

- [ ] WASD — движение
- [ ] Мышь — поворот камеры от первого лица
- [ ] Shift — спринт
- [ ] Ctrl — присесть
- [ ] Q/E — наклон головы (lean)
- [ ] Space — прыжок
- [ ] E или LMB (по настройкам interaction) — взаимодействие с дверью/ящиком/запиской

## 5. Системы

- [ ] Подход к записке → появляется prompt «Прочитать» (или аналог); интеракция → открывается NoteViewer с текстом «День 1. Дверь захлопнулась…»
- [ ] Чтение записки → паранойя вырастает на 10
- [ ] Открытие ящика → должен работать как Amnesia-дверь (тянуть мышью)
- [ ] Tab или I — открывает инвентарь (2×4 grid, русские подписи, пауза игры)
- [ ] Esc в инвентаре — закрывает его
- [ ] Пройти через выходную дверь (ToCorridor trigger Area3D) → сцена меняется на `bunker_corridor.tscn`
- [ ] В коридоре зайти в DarkZone (центр) → паранойя растёт, выйти — стабилизируется
- [ ] Подойти к батарейке и взаимодействовать → пропадает, в инвентаре появляется запись «Батарейка», фонарик получает +50 заряд
- [ ] Пройти через северную дверь коридора (BackToEntrance trigger) → возврат в entrance

## 6. HUD

- [ ] Справа внизу — полоса заряда батареи (зелёная при 100%)
- [ ] Слева внизу — "глаз паранойи" (белый при 0, краснеет с ростом)
- [ ] По центру — маленький крестик-прицел
- [ ] При подборе предмета — тост сверху "Подобрано: …" на 3 секунды

## 7. Сохранения (опционально)

- [ ] В консоли Godot: `SaveManager.save_game(0)` → появляется `user://saves/slot_0.save`
- [ ] Перезапуск → `SaveManager.load_game(0)` → paranoia_level и game_time восстанавливаются

## 8. Чистота

- [ ] После 30 секунд игры — консоль без рекуррентных ошибок
- [ ] FPS стабилен (должен быть 60+ на среднем железе, в `scenes/main.tscn` мог быть counter)
